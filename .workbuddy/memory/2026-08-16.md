# 2026-08-16

## 搭建 Tmoi 个人艺术网站（Next.js 版）

- 技术栈：Next.js 14 (App Router, TS) + Tailwind v3 + Framer Motion + Three.js(@react-three/fiber) + Howler.js。
- 暗色策展风配色：ink #0a0a0a / paper #f5f2ec / accent #ff5a1f。
- 页面：首页(Hero+Three.js 生成背景)、/works(媒介筛选)、/works/[slug](五模块详情)、/about、/contact。
- 五媒体模块：文字介绍、图片画廊(lightbox)、视频播放、网页互动(Three.js echo-sphere / Canvas2D 粒子花园)、声音(Howler + Web Audio 频谱可视化，默认关闭)。
- 数据驱动：`data/works.json` + `lib/types.ts`。示例作品 echo-realm 覆盖全部五种媒体；另含 silent-range(图)、tide(影像+声音)、pixel-garden(互动) 用于演示筛选。
- 占位素材脚本：`scripts/generate-svgs.mjs`(SVG)、`scripts/generate-audio.mjs`(WAV)、`scripts/generate-video.py`(MP4, 用 imageio-ffmpeg 自带 ffmpeg)。
- 注意：本环境曾自动 overlay 一个 Vite 脚手架(src/, index.html, vite.config.ts)并改写 package.json/tsconfig/tailwind，已清理并恢复 Next.js 配置。若再次出现 Vite 文件，需再次清理。
- 部署：Vercel（vercel.json 仅设静态素材缓存头）。`npm run build` 通过，11 个页面静态生成。
- 本地预览：注意环境有 HTTP_PROXY 拦截 localhost，curl 需 `env -u HTTP_PROXY ... --noproxy '*'` 才能直连 127.0.0.1:3000。
